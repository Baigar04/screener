# Screener

Screener propio de mercados con datos públicos y gratuitos.

- **Web:** GitHub Pages (`index.html`, `assets/`).
- **Datos:** `scripts/fetch_macro.py` genera `data/macro.json` (FRED, BCE, Banco Mundial, FMI).
- **Actualización:** `.github/workflows/update.yml`, de lunes a viernes tras el cierre de EE. UU., y a mano desde *Actions → Actualizar datos → Run workflow*.

Herramienta de análisis con fines informativos. No es asesoramiento financiero.
